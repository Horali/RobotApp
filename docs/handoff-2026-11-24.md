## 6. Critical gotchas & verification recipes

- **WAL SQLite**: Never open `warmup.db` or `robot.db` with `?immutable=1` — it ignores `-wal` and reads stale state.
- **Secondary-user media push**: `adb push` cannot write `/storage/emulated/<user>` due to SELinux. `robotapp/media.py` uses `adb reverse` + the space's own Chrome.
- **Foreground detection**: `mCurrentFocus` prints per root on Infinix XOS — always read `topResumedActivity`. And UI hierarchy only sees whichever Android user is in front (`enter_space` before reading/tapping).
- **Android 13 secondary-user clipboard**: `u2`'s `device.clipboard` returns `None` for User 10/11/12. `YouTubePoster` reads links via `KEYCODE_PASTE` (`279`) into the foreground Search box (`_paste_clipboard_via_search`); TikTok/Instagram link readers haven't needed that yet because TikTok/IG laptop checks verified via headless Chrome instead:
