## Gotchas that will bite (learned the hard way, all in the code now)

- **Never run a sitting without `"user"`** — RobotApp refuses it now, but ClipMaker must keep sending it.
- The screen only ever shows **one user**: `robot screen --user N` switches first; a probe that forgets
  reads user 0's launcher and every selector "fails" for no reason (that wasted ~40 minutes once).
- **`mCurrentFocus` is printed per root** on this XOS build — the robot reads `topResumedActivity` instead.
- SFA (sing-box) asks **"Are you sure to import remote profile …?"** before importing; the profile list
  behind the dialog stays readable, so a naive check thinks the import finished.
- Typing goes through the field's own `setText` (**index 0 for Google's single field**; Instagram's form has
  two EditTexts). Never submit an empty form.
- `adb push` cannot write `/storage/emulated/11` (SELinux). Media into a space goes through its browser.
- The owner user (0) is **the user's own life**: G2G + their personal Instagram "Faiz". Nothing the robot
  does for the throwaway may touch it.
